# SQL Server Database Designs
A collection of database design projects created using SQL Server as part of my database learning journey. These projects focus on database modeling, entity relationships, normalization, business rules implementation, and real-world system design without application-layer code.

## Included Projects
### 1. Clinic Management Database
A healthcare database that manages patients, doctors, appointments, medical records, prescriptions, and payments.

**Concepts:**
- Table-Per-Type (Inheritance)
- One-to-Many Relationships
- Medical Records Management
- Appointment Scheduling
- Payment Tracking

---

### 2. Library Management Database
A library system that manages books, copies, borrowing operations, reservations, fines, and system settings.

**Concepts:**
- Book & Copy Separation
- Borrowing Lifecycle
- Reservation System
- Fine Calculation
- Configuration Tables

---

### 3. Karate Club Management Database
A club management database that handles members, instructors, subscriptions, belt examinations, payments, and ranking progression.

**Concepts:**
- Many-to-Many Relationships
- Junction Tables
- Membership Tracking
- Belt Ranking System
- Subscription Management

---

### 4. Car Rental Database
A vehicle rental system that manages customers, vehicles, bookings, returns, maintenance operations, and rental transactions.

**Concepts:**
- Rental Lifecycle Management
- Financial Transactions
- Vehicle Maintenance Tracking
- Lookup Tables
- Historical Data Tracking

---

### 5. Online Store Database
An e-commerce database that manages products, categories, images, customers, orders, payments, shipping operations, and product reviews.

**Concepts:**
- E-Commerce Data Modeling
- Order Processing
- Product Catalog Design
- Payment Tracking
- Shipping Management
- Product Reviews

## Technologies
- SQL Server
- Relational Database Design
- Entity Relationship Modeling (ERD)
- Normalization
- Business Rule Modeling

## Purpose
These database designs were created to practice building real-world relational database systems and to strengthen skills in database architecture, data modeling, and business process analysis.
